About KAVACH-NET

What this is

KAVACH-NET (SIH26189) is an investigation-support prototype that turns fragmented crime-related records into an entity-relationship network, then applies transparent, explainable rules to surface leads an investigator should review.

Pipeline: Input Data → Entity Extraction → Relationship Extraction → Entity Normalization → Network Graph → Graph Analysis → Pattern Detection → Investigator Insights.

Investigation Support Notice: KAVACH-NET identifies potentially significant relationships and patterns from available data. It does not determine guilt or criminal responsibility. All alerts require investigator review and verification.
